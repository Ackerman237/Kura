# Credits & Third-Party Acknowledgments

**Kura (蔵)** is a self-hosted, personal media reader and personal indexer developed for private study, accessibility, and archival purposes. 

This project relies on and acknowledges various community upstream sources, open-source libraries, and content platforms.

---

## 📡 Media Providers & Source Sites

Kura acts strictly as a **client-side user-agent and personal parser**, fetching publicly accessible content from the following platforms upon user request:

| Provider | Media Type | Purpose & Scope |
|:---|:---|:---|
| **Doujindesu** | Manga / Manhwa / Doujinshi | Multi-chapter catalog search, metadata indexing, and chapter reading |
| **NekoPoi** | Anime Streaming & Direct Links | Episode listings, release metadata, and direct download source extraction |
| **Hentai.tv** | Anime HLS Streaming | Video player integration, m3u8 resolution, and episode navigation |
| **Eporner** | Video Clips / Tube | Multi-resolution stream parsing and direct video stream resolution |

> [!NOTE]
> All trade names, trademarks, and source content belong entirely to their respective rights holders and platforms. Kura does not alter or re-brand upstream video watermarkings or artist watermarks.

1. **Zero Central Hosting**: Kura does not host, upload, scrape into a public database, or redistribute any media files. All parsed content is retrieved on-demand directly by your local self-hosted instance from public third-party endpoints.

## 🛠️ Open Source Ecosystem

Kura's frontend and backend are powered by these core open-source technologies:

- [Node.js](https://nodejs.org/) — Event-driven zero-dependency backend runtime (built-in HTTP/HTTPS/Streams).
- [Vue.js 3](https://vuejs.org/) — Progressive reactive user interface framework.
- [HLS.js](https://github.com/video-dev/hls.js/) — Media Source Extensions based HTTP Live Streaming client.
- [Canvas Confetti](https://github.com/catdad/canvas-confetti) — Milestone delight micro-animations.
- [Lucide Icons](https://lucide.dev/) — Clean, crisp open-source iconography.
- [Google Fonts](https://fonts.google.com/) — Plus Jakarta Sans & JetBrains Mono typography.
